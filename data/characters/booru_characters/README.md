# Sn0w123/booru-characters local evaluation copy

Downloaded for isolated evaluation only. This directory is not read by the Illustrious to Klein pipeline, its MCP server, character-reference search, cache, runners, or workflows.

Contents:

- characters.jsonl: source dataset, one JSON object per character tag.
- dataset_info.json: source feature description.
- Use scripts/query_booru_characters.py for local read-only lookups.

Source: https://huggingface.co/datasets/Sn0w123/booru-characters
