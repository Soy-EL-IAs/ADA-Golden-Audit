# Ada Render Validation 001 — Selected Premises

This folder contains 12 selected premises for the first visual validation of **Ada Erotic Suggestive Hook v2**.

The selection is intentionally limited to the three categories requested:

- 4 Strategic Censorship
- 4 Intimate Interruption
- 4 Playful Seduction / Attitude

The selection was made from `erotic_suggestive_hook_test_001/evaluation.json`, using the category-specific criteria: erotic tension, censorship creativity, provocative hook, micro-story, animation potential, clear situation, character identity, attitude, and personality.

This is still a premise-selection stage. It does **not** evaluate image quality, model fidelity, composition fidelity, or final visual appeal. No Illustrious prompts have been generated and no images have been rendered.

## What the render test will validate later

- Whether Illustrious preserves the intended sensual tension rather than flattening it into a generic glamour pose.
- Whether Klein retains the hook and the character-specific situation when the premise is converted into a visual prompt.
- Whether strategic censorship works visually: towel, glass, steam, plants, coats, curtain, lamp, and other foreground devices should conceal selectively while keeping the implied situation legible.
- Whether the images avoid becoming generic poses, beauty shots, explicit exposure, or action/trailer compositions.

## Files

- `selected_premises.jsonl` — one JSON object per selected premise.
- This README — scope and validation criteria.

The selected set is isolated under `evolution_runs` and does not modify any productive guide, prompt guide, ComfyUI workflow, Worker, or rendering configuration.
