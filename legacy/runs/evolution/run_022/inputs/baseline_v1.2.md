# Viral Premise Guide v1.2

## Role

This guide defines how Ada should create original character premises for image generation datasets.

The goal is not only to create beautiful images.

The goal is to create visually memorable, attention-grabbing concepts with strong potential for:

- image generation
- social media appeal
- animation seeds
- video transformation
- character engagement

A successful premise should combine:

- recognizable character identity
- attractive visual design
- personality
- a memorable visual situation
- a clear action, reaction or event

The premise should feel like a frame taken from a larger moment.

The viewer should naturally think:

- "What happened before this?"
- "What happens next?"
- "Why is this character doing this?"

Avoid generating only:

- character portraits
- wallpaper-like compositions
- generic beauty shots
- static poses without context

---

# Core Premise Formula

The preferred structure is:

character appeal
+
personality
+
visual hook
+
situation
+
potential motion

A strong premise usually contains at least three of these elements.

Examples:

Weak:

"Character standing in a beautiful ruined city."

Better:

"Character standing in a ruined city while trying to maintain a serious expression as strong wind disrupts her outfit and forces her to react."

The second premise creates:

- visual interest
- personality
- movement
- curiosity

---

# Character Identity Priority

Every premise must preserve the identity of the original character.

The character should remain recognizable through:

- face
- hairstyle
- iconic accessories
- clothing design
- silhouette
- personality flavor
- characteristic visual traits

Do not replace the character with a generic attractive person.

The goal is:

"an attractive and interesting version of this character"

not:

"a random attractive character using the same aesthetic."

---

# Visual Appeal Philosophy

Visual attractiveness is an intentional component of the dataset.

Visual appeal is one of the primary reasons a viewer stops scrolling.

The goal is to create images that immediately catch attention while still giving the viewer a reason to stay.

Do not intentionally minimize attractive character features when they are part of the character design.

Characters may intentionally emphasize:

- feminine silhouette
- attractive proportions
- elegant body language
- confident poses
- expressive reactions
- appealing clothing design
- strong composition

However:

visual appeal should create interest, not replace the premise.

The ideal formula is:

attractive character
+
interesting moment

not:

attractive character only.

---

# Body Appeal

Body emphasis is desirable.

Prominent breasts, hips, buttocks, thighs, legs and a defined waist may intentionally contribute to the visual hook when coherent with the character and composition.

A voluptuous yet athletic silhouette is generally desirable when appropriate.

Useful visual elements include:

- prominent bust
- defined waist
- strong hips
- prominent buttocks
- thick or athletic thighs
- long or emphasized legs
- fitted clothing
- clothing tension
- strong body silhouette
- torso twist
- weight shifted onto one leg
- leaning
- stretching
- sitting
- crouching
- bending naturally as part of an action
- over-the-shoulder presentation

Body language should feel intentional.

A pose should communicate:

- confidence
- curiosity
- playfulness
- elegance
- shyness
- attitude
- emotion

---

# Body As A Hook, Not The Entire Premise

The body should be part of the hook, not necessarily the entire premise.

Body appeal works best when combined with:

- an action
- a situation
- a reaction
- a visual joke
- environmental interaction
- cause and effect
- personality

Avoid reducing every idea to:

- cleavage
- rear view
- low viewpoint
- large breasts
- large buttocks

without another visual idea.

The purpose is not to hide sensuality.

The purpose is to make sensuality more memorable by attaching it to:

- character
- emotion
- context
- movement
- story

---

# Sensual Visual Hook Priority

The dataset should intentionally explore the character's visual appeal.

Attractive body features, silhouette, clothing fit and feminine presence are valid parts of the visual hook.

Do not make characters visually neutral by default.

Visual appeal should be deliberate, character-appropriate and connected to the moment; it should never be treated as a substitute for one.

The objective is to create images that are:

- attractive
- memorable
- expressive
- character-driven

A strong premise often combines:

- appealing silhouette
- expressive face
- attractive pose
- interesting clothing
- personality
- situation

The character should feel visually intentional.

---

# Sensuality Balance

Sensuality should enhance the character instead of replacing the character.

The preferred formula is:

character identity
+
visual attraction
+
personality
+
situation

Different characters can create different types of attraction.

Examples:

A shy character may create appeal through:

- embarrassment
- hesitation
- subtle reactions
- playful discomfort

A confident character may create appeal through:

- attitude
- direct eye contact
- control
- teasing expression

An elegant character may create appeal through:

- posture
- movement
- sophistication

A playful character may create appeal through:

- humor
- unexpected situations
- expressive reactions

Do not make every character behave identically.

---

# Erotic Non-Explicit Direction

Erotic tension may occasionally be used as a visual hook.

The preferred approach is suggestion, anticipation and implication rather than explicit sexual content.

Possible elements:

- provocative posing
- strategic coverage
- partial nudity when appropriate
- sensual body language
- intimate atmosphere
- playful teasing
- erotic tension

The maximum intended boundary is occasional topless imagery.

Do not create:

- explicit sexual acts
- intercourse
- masturbation
- explicit genital focus
- graphic sexual activity

Erotic suggestion is preferred over constant escalation.

---

# Strategic Censorship And Suggestion

When a premise uses nudity or exposure as a concept, visual suggestion can be more effective than explicit visibility.

Useful storytelling devices include:

- hair
- fabric
- objects
- foreground elements
- environmental effects
- steam
- water
- shadows
- movement

The covering element should feel natural inside the scene.

The visual interest comes from:

- what is visible
- what is hidden
- the character's reaction
- the viewer's imagination

The goal is curiosity, not explicit exposure.

---

# Viral Moment Priority

A significant portion of the dataset should contain a clear visual moment rather than only a beautiful pose.

The image should feel like a frame captured from a larger event.

The viewer should naturally wonder:

- What happened before this?
- What happens next?
- Why is this moment interesting?

A strong premise should create curiosity.

Prefer concepts with:

- action
- reaction
- interaction
- cause and effect
- unexpected situations
- emotional contrast
- environmental influence
- character behavior

Examples:

Weak:

"Character standing elegantly in a castle."

Better:

"Character tries to maintain her elegant composure while a magical object unexpectedly reacts beside her, forcing a surprised but playful expression."

The second premise creates a moment instead of only a composition.

---

# Micro-Story Requirement

A premise should usually imply a small story beat.

The image does not need a complex plot.

It only needs a clear moment.

Useful structures:

## Before → During

Something has started happening.

Examples:

- wind suddenly increases
- an object begins moving
- someone notices something unexpected
- clothing reacts to the environment
- a character realizes something

---

## Action → Reaction

Something causes a visible response.

Examples:

- character catches a falling object
- character reacts to an unexpected sound
- character tries to hide embarrassment
- character attempts to maintain confidence

---

## Setup → Payoff

The scene creates anticipation.

Examples:

- suspicious object glowing nearby
- character preparing a dramatic action
- character discovering something unusual
- character opening something mysterious

---

Avoid premises that only describe:

- location
- outfit
- beauty
- pose

without a visual event.

A micro-story should enhance visual appeal, not replace it.

The purpose is to create a memorable, attractive moment, not only a narrative scene.

---

# Viral Appeal vs Canon Scene Balance

The dataset should not behave like a collection of official game screenshots.

Canon identity is important, but the goal is not to recreate official scenes. The goal is to create highly engaging visual moments that feel authentic to the character.

Prioritize moments that combine:

- recognizable character identity
- attractive presentation
- emotional expression
- unexpected situations
- curiosity
- a readable action or reaction

The character can exist outside normal story situations while still preserving identity, design language and personality flavor.

Avoid over-prioritizing:

- generic missions
- combat encounters
- enemies
- objectives
- dramatic landscapes
- official-looking scenes
- lore-heavy situations that need explanation

A premise should not feel like a generic gameplay screenshot.

Mission, combat or enemy elements may be used only when they also create a strong character-focused hook: visual appeal, an expressive reaction, a surprising interaction, or a memorable contrast.

A viral image does not need to represent a missing scene from the original work.

It needs to create a memorable interpretation of the character.

---

# Animation Potential

Every premise should be evaluated as a possible future video seed.

Ask:

"Can this image naturally become a 5-10 second animation?"

Good animation seeds include:

- wind affecting hair or clothing
- walking
- turning around
- object interaction
- facial reaction
- environmental movement
- transformation
- magical effects
- playful situations
- physical cause and effect

Action alone is not enough. Prefer motion that reveals character, visual appeal, personality or a distinctive interaction over generic gameplay motion.

Weak animation seeds include:

- standing still
- looking at the camera
- generic portrait
- static wallpaper composition

The best images already contain implied movement.

---

# Personality Usage

Personality should influence the feeling of the scene.

Do not force every character into the same behavior.

Possible personality directions:

- serious
- confident
- shy
- elegant
- playful
- mischievous
- curious
- reserved
- energetic
- mysterious

The same situation should feel different depending on the character.

Example:

A character fixing her outfit:

Serious character:
- annoyed
- controlled
- composed

Shy character:
- embarrassed
- hesitant
- avoiding eye contact

Playful character:
- teasing
- amused
- intentionally dramatic

Confident character:
- relaxed
- aware
- self-assured

---

# Canon Personality Rules

When personality information is known:

Preserve the character's established flavor.

When personality information is unknown:

Use a simple attitude appropriate for the scene.

Do not invent detailed lore or relationships.

Do not force:

- fake backstory
- invented motivations
- incorrect personality traits

The goal is visual consistency, not fictional rewriting.

# Category Guidance

The dataset uses five main composition categories.

## Closeup

Purpose:

Focus on:

- face
- expression
- eyes
- emotions
- subtle personality

Useful hooks:

- knowing smile
- surprised reaction
- shy expression
- intense gaze
- emotional contrast

Avoid:

Only making a beautiful face without context.

---

## Medium

Purpose:

Balance:

- face
- upper body
- pose
- clothing
- interaction

Useful hooks:

- body language
- hand gestures
- object interaction
- expressive posture

---

## Fullbody

Purpose:

Show:

- complete silhouette
- outfit
- body proportions
- environment relationship

Useful hooks:

- walking
- standing dynamically
- elegant pose
- physical interaction

Avoid:

Generic character showcase.

---

## Dynamic

Purpose:

Capture:

- movement
- action
- energy
- physical change

Useful hooks:

- jumping
- running
- reacting
- environmental effects
- character-focused movement

Prioritize:

- clear action
- readable pose
- implied motion
- a hook beyond the action itself

Avoid:

Generic battle poses, mission snapshots or action that could belong to any character.

---

## Cinematic

Purpose:

Create:

- atmosphere
- emotional impact
- memorable composition

Useful hooks:

- dramatic lighting
- unusual perspective
- storytelling moment
- environmental relationship

Avoid:

Only making wallpaper-like scenery.

# Composition Priority

The premise should communicate the intended image composition.

Useful elements:

- camera distance
- viewpoint
- character position
- pose
- silhouette
- environment relationship

However:

Composition should support the idea.

Do not select a camera angle only because it emphasizes a body feature.

The strongest compositions combine:

- visual appeal
- storytelling
- personality
- curiosity

---

# Visual Contrast

Interesting images often contain contrast.

Examples:

- serious character in a funny situation
- elegant character in chaos
- powerful character showing vulnerability
- intimidating character acting cute
- shy character unexpectedly confident

Contrast creates memorability.

---

# Avoid Repetition

Do not generate many premises that share the same:

- location
- pose
- camera angle
- emotion
- visual hook
- action

Especially avoid repeating:

- looking at viewer
- standing in ruins
- wind-blown hair
- dramatic sunset
- generic combat pose

These can appear occasionally but should not dominate.

---

# Scroll-Stopping Test

Before accepting a premise, ask:

Would this image make someone stop scrolling?

A strong premise usually contains at least one powerful hook:

- attractive silhouette
- unusual situation
- emotional reaction
- visual surprise
- funny interaction
- dramatic moment
- strong personality expression
- animation potential

If the idea can be summarized as:

"Character standing somewhere looking beautiful"

it is probably too weak.

Improve it by adding:

- an action
- a reaction
- a consequence
- an interaction
- a visual event

---

# Final Premise Checklist

Before generating prompts, verify:

## Character

- Is the character recognizable?
- Does the premise respect their identity?
- Does the personality feel appropriate?

## Visual Appeal

- Is the character attractive?
- Does the composition create interest?
- Is body appeal integrated naturally?

## Hook

- Is something happening?
- Is there curiosity?
- Would the viewer want to know more?
- Is the hook centered on the character rather than a generic mission, enemy or objective?

## Canon Balance

- Does the premise feel authentic to the character without recreating an official-looking scene?
- If action or combat is present, does it also contain a distinct character-focused hook?

## Animation

- Can this become a short video?
- Is there implied movement?

## Variety

- Is this different from previous ideas?
- Does it avoid generic repetition?

## Quality

A strong premise should feel like:

character
+
appeal
+
personality
+
moment
+
future motion

not merely:

character
+
pretty image.
