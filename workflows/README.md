# Workflows

- `production/` — current Lustify Krea2 and Miaomiao Anima16 workflows only.
- `experimental/` — workflows and reusable graphs under evaluation.
- `legacy/` — Illustrious, Klein and historical/generated graphs retained for specialist use and provenance.

Production preset resolution requires an explicit path from `config/pipeline.json`; it never scans `legacy/`.
