# Legacy/debug workflows

Files in this directory are retained as historical evidence and test fixtures only.
They are not valid ADA production workflows and must never be submitted by a production runner.

`illustrious_to_klein_batch_base_ui.json` contains live Illustrious, Klein, and Compare branches in one graph.
It is intentionally quarantined here so production code cannot select it by the former root-level path.

`krea/` and `generated/` contain historical chained-workflow materials, including the Chel incident evidence. They are excluded from production workflow discovery and the production Asset Library.
