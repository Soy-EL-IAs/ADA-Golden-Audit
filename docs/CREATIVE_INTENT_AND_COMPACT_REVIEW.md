# Creative intent and compact review

For every new Mission, Create persists a `CreativeIntentEnvelope`. Precedence is deterministic:

`USER LOCKED INTENT > CHARACTER CONTRACT IMMUTABLES > SELECTED CREATIVE CONCEPT > RENDERER PREFERENCES`.

M1 creates twelve compact sketches only. M3/M4 select them, then only selected sketches expand to
a render premise. `ResolvedRenderSpec v3` merges locked values and the pre-render linter rejects
contradictions before ComfyUI. A locked visible setting receives environmental anchors.

Visual Review v3 receives the current spec's expected visibility, not historical character lore.
It returns five compact subscores, defects, hard failures, and a short summary. ADA computes the
weighted rating and applies conservative anatomy/identity/locked-constraint caps. v1/v2 artifacts
remain read-only compatible and are never assigned invented ratings.
